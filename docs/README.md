# Bibliographic metadata

`references.json` contains a 60-record metadata pool; the manuscript selects
only cited works. `keys.json` maps citation keys to those records. The
remediation retrieved primary Crossref/DataCite records and verified the
DOI-less LightGBM work against the NeurIPS proceedings. Registry identity and
bibliographic fields do not establish substantive support for every sentence.

Manuscript, title-page and response builders are not included.
